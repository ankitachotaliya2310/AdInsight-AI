# AdInsight AI

## Project Overview

AdInsight AI is an end-to-end Advertising Analytics Platform built using Google BigQuery, Python, Machine Learning, and Streamlit.

The goal is to help marketing teams analyze campaign performance, understand user behavior, predict conversions, and generate actionable business recommendations.

---

# Business Problem

Marketing teams spend significant budgets on digital advertising but often struggle to answer questions like:

- Which traffic source brings the most valuable users?
- Which campaigns generate the highest revenue?
- Which devices convert the best?
- How should advertising budgets be optimized?

AdInsight AI solves these problems using data analytics and machine learning.
